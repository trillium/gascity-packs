# gascity-packs

Public Gas City packs by trillium.

| Pack | What it is |
|------|------------|
| [`firstmate`](firstmate/README.md) | A firstmate-style Mayor that works inside Gas City rules: a plain-outcome communication contract and a durable decision ledger. Imports gastown and patches its Mayor and refinery prompts. |

Install a pack with `gc import add`:

```bash
gc import add https://github.com/trillium/gascity-packs/tree/main/firstmate
```

Each pack's README says what has and has not been verified.
